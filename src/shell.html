Which day it is, is decided here rather than by the device you happen to be holding. Set this and a flight stops rewriting your queue.

Rolling a task off a day that has already passed counts one push — at most one per day, however long you were away.

Tasks carry a shape (deep / admin / errand / social) and a size, never a start time. A task you defer to a later day earns a push mark — at three, your secretary stops letting it slide quietly.
